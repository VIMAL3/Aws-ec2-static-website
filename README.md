# AWS IAM & EC2 Static Website Deployment

Static HTML webpage deployed on an **Amazon EC2** instance using **Apache (`httpd`)** for my AWS Cloud Internship.

## Key Highlights
* **IAM:** Users, groups, roles, JSON policies, MFA, and least privilege.
* **EC2:** Amazon Linux 2023 instance launched with SSH and HTTP (port 80) security group rules.
* **Web Server:** Installed `httpd`, started the service, and hosted `index.html` on `/var/www/html/`.
